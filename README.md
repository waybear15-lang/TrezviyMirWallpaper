# Трезвый Мир — космическая заставка

Отдельное Android-приложение с живыми обоями для бренда «Трезвый Мир».

## Что внутри

- полностью программная отрисовка под любое соотношение сторон;
- неоновый глобус с сеткой вместо изображения из референса один в один;
- мерцающие звёзды и светило с 24-часовой орбитой против часовой стрелки;
- восход на востоке в 06:00, верхняя дуга до заката на западе в 18:00 и нижняя дуга ночью;
- медленное вращение планетарной сетки по часовой стрелке;
- название рисуется Android и остаётся резким на любом экране;
- нет геолокации, сети, рекламы и аналитики;
- анимация останавливается, когда обои не видны;
- системный экран предпросмотра и установки живых обоев.

## Установка

1. Установите `TrezviyMirWallpaper-1.2.0-debug.apk` на Android 9 или новее.
2. Откройте приложение «Трезвый Мир».
3. Нажмите «Установить живые обои».
4. В системном окне выберите экран блокировки, если оболочка телефона предлагает такой выбор.

Android и оболочки производителей по-разному обрабатывают живые обои. Некоторые устройства ставят их сразу на главный экран и экран блокировки, а некоторые не разрешают отдельные живые обои только для блокировки.

## Сборка

Требуются JDK 17 и Android SDK 36.

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
